Install Rondo

Put Rondo on your Innioasis Y1 straight from this page, over USB. Nothing to install on your computer.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer, or in Chrome on an Android phone with a USB-C cable. Or use the install script.
Your Y1 needs the Android 4.2 (Dev) firmware first. If it doesn't have it yet, follow step 1 of the install guide, then come back.
  1. 1

    Connect your Y1

    ✓

    Plug the Y1 into this computer with a USB-C data cable and switch it on. Close the Innioasis Updater if it's open.

  2. 2

    Install Rondo

    ✓

    Looking for the latest Rondo…

    This Y1 has a Rondo signed with a different key, for example one built from source. To install this one, the old one has to go first, and its settings with it: the theme, saved radio stations and the server connection. Your music and Wi-Fi networks stay.

  3. 3

    Done

    ✓

    The Y1 will start in Rondo from now on.

    Next, set up a server for YouTube Music and YouTube, or learn the controls. You can unplug the Y1.

The Y1 doesn't show up, or connecting fails
  • Try another cable. Many USB-C cables only charge.
  • Only one program can use the Y1's USB connection at a time. Close the Innioasis Updater, and if you've used adb, run adb kill-server. Then unplug the Y1, plug it back in and try again.
  • Windows: the Y1 needs Google's USB driver (it shows up as "Android ADB Interface" in Device Manager).
  • Linux: your user needs access to the device. A udev rule for USB ID 0bb4:0c03, or the plugdev group, does it.
  • Still stuck? The install script does the same steps from a terminal.
This page talks to your Y1 from your browser. Nothing is uploaded anywhere.
